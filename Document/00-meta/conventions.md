# 문서 작성 규칙

- [홈](../Home.md)에서 주제별 인덱스로 이동한다. 새 노트를 만들면 해당 폴더의 `index.md`에 상대 경로 링크와 한 줄 설명을 추가한다.
- Vault 내 링크는 대상까지의 상대 경로를 쓴다. 저장소의 코드나 설정은 Vault 밖에 있으므로, 아래 예처럼 `근거 경로:` 뒤에 저장소 루트 기준 백틱 경로로 적는다.
- 현재 확인된 구현, 합의한 결정, 아직 검증하지 않은 절차를 구분한다. 저장소에서 확인할 수 없는 기능이나 실행 결과를 사실처럼 쓰지 않는다.
- 프로젝트 구조는 `10-architecture/`, 결정과 대안은 `20-decisions/`, 반복 절차는 `40-guides/`, 다음 작업의 인수인계는 `50-worklog/`에 둔다. 일회성 작업 기록을 쌓거나 같은 설명을 여러 문서에 복제하지 않는다.
- 지속적으로 참고할 지식이 바뀌지 않았으면 파일을 고치지 않는다. 노트 탐색 구조를 바꿀 때만 관련 인덱스와 홈을 맞춘다.
