# 캐릭터 이동과 자세

이동·자세 규칙의 확정 기획이다. 입력 이름과 판정 시간은 [조작과 전투 규칙](controls.md), 무기와 타격 규칙은 [전투 시스템](combat-system.md)에 있다.

## 자세 상태

캐릭터는 항상 다음 9개 상태 중 하나에 있다. 상태 이름은 무기 벌어짐 표([전투 시스템](combat-system.md))와 코드의 상태 열거형에서 같은 문자열을 쓴다.

| 상태 | 서 있는가 | 이동 중인가 | 조준 중인가 | 공중인가 |
| --- | --- | --- | --- | --- |
| `Stand_Idle` | 서기 | 아니오 | 아니오 | 아니오 |
| `Stand_Walk` | 서기 | 걷기 | 아니오 | 아니오 |
| `Stand_Run` | 서기 | 달리기 | 아니오 | 아니오 |
| `Stand_Aim` | 서기 | 조준 이동 | 예 | 아니오 |
| `Crouch_Idle` | 앉기 | 아니오 | 아니오 | 아니오 |
| `Crouch_Walk` | 앉기 | 걷기 | 아니오 | 아니오 |
| `Crouch_Aim` | 앉기 | 조준 이동 | 예 | 아니오 |
| `Jump_Fall` | 서기 | 공중 | 아니오 | 예 |
| `Roll` | 서기 | 구르기 | 아니오 | 아니오 |

- 구르기가 끝나면 앉기 선입력 여부에 따라 `Crouch_Idle` 또는 `Stand_Idle`로 간다.
- 공중에서 앉기 버튼을 눌러도 상태는 바뀌지 않고, 착지할 때 앉기 선입력을 소비한다.
- 조준 중에는 앉기 입력이 서기/앉기만 바꾸고 조준은 유지된다.

## 이동

캡슐은 서기일 때 반높이 88(전체 176), 앉기일 때 반높이 48(전체 96)이다. 최대 이동 속도는 `CharacterMovementComponent`의 `MaxWalkSpeed`로 두고, 상태가 바뀔 때 한 번만 갱신한다.

| 상태 | 최대 이동 속도 |
| --- | --- |
| `Stand_Idle` / `Stand_Walk` | 400 |
| `Stand_Run` | 600 |
| `Stand_Aim` | 250 |
| `Crouch_Idle` / `Crouch_Walk` | 200 |
| `Crouch_Aim` | 130 |
| `Roll` | 900 (0.45초 동안만) |
| `Jump_Fall` | 공중 이동 400, 공중 제어 0.35 |

- 방향은 카메라가 보는 월드 기준으로 WASD를 조합해 정한다. 캐릭터는 이동 방향으로 회전하되, 조준 중에는 마우스가 가리키는 방향으로 회전한다.
- 달리기는 Shift를 누르고 있는 동안 유지되고, Shift를 떼면 즉시 걷기로 돌아간다.

## 점프

- 입력: Space. 바닥에 있을 때만 발동한다.
- 수치: `JumpZVelocity` 620, `GravityScale` 1.5 → 최고 높이 약 130cm.
- 점프 시작 순간 [전투 시스템](combat-system.md)의 총구 충격(+25°, 2.0초 회복)이 한 번 걸린다.
- 공중에서는 앉기·구르기를 시작할 수 없다. 착지 판정은 캡슐이 바닥에 닿는 순간이다.

## 앉기

- 입력: C. 누를 때마다 서기/앉기를 전환한다(홀드 아님).
- 앉는 순간 캡슐 반높이가 48로 줄고 카메라가 40cm 내려간다. 서는 순간 원래 값으로 돌아간다.
- 머리 위에 장애물이 있으면 앉은 상태를 유지하고, 서기 입력은 보류됐다가 공간이 생기면 적용한다.
- 앉으면 이동 속도가 200(조준 중 130)으로 줄고, 탄퍼짐과 총구 벌어짐이 줄어든다.

## 구르기

- 입력: 이동 키를 누른 상태에서 Shift를 0.25초 안에 두 번 탭한다(제자리 두 번 탭은 달리기로 처리).
- 지속 시간 0.45초. 그동안 이동 속도 900으로 입력 방향(입력이 없으면 바라보는 방향)으로 나아간다.
- 구르는 동안 사격·재장전·조준을 시작할 수 없다.
- **피격 면역은 없다.** [조작과 전투 규칙](controls.md)의 기존 규칙을 그대로 따른다. 구르기는 회피가 아니라 이동 기술이다.
- 구르기 중 C를 누르면 선입력으로 기록하고, 구르기가 끝나는 순간 앉은 상태로 전환한다. 누르지 않았으면 서서 끝난다.
- 구르기 중에는 중력이 적용되지 않고, 끝나는 순간 바닥에 착지한다.

## 상태 전이

| 현재 | 입력 | 다음 |
| --- | --- | --- |
| `Stand_Idle` | 이동 | `Stand_Walk`, Shift면 `Stand_Run` |
| `Stand_Walk` / `Stand_Run` | 입력 없음 | `Stand_Idle` |
| `Stand_*` | C | `Crouch_*` |
| `Crouch_*` | C (머리 위 공간 있음) | `Stand_*` |
| `Stand_*` / `Crouch_*` | RB 홀드 | `Stand_Aim` / `Crouch_Aim` |
| `*_Aim` | RB 뗌 | 서기/앉기 상태로 복귀 |
| `Stand_*` / `Crouch_Idle` | Space | `Jump_Fall` |
| `Jump_Fall` | 착지 | 앉기 선입력이 있으면 `Crouch_Idle`, 없으면 `Stand_Idle` |
| `Stand_Walk` / `Stand_Run` / `Crouch_Walk` | Shift 두 번 탭 | `Roll` |
| `Roll` | 0.45초 경과 | 선입력 있으면 `Crouch_Idle`, 없으면 `Stand_Idle` |

## 구현 규칙

- 이동은 `ACharacter`의 `CharacterMovementComponent`를 쓴다. 별도 이동 컴포넌트를 새로 만들지 않는다.
- 상태 문자열은 `FName` 또는 열거형 한 곳에서만 정의하고, 애니메이션·탄퍼짐·총구 벌어짐이 같은 값을 참조한다.
- 상태 전이는 틱마다 재계산하지 않고, 입력·착지·구르기 종료 같은 사건에서만 갱신한다.
