# 조작과 전투 규칙

## 입력

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 기본 기동 |
| Space | 점프 |
| Shift 홀드 | 달리기 |
| 이동 중 Shift 두 번 탭 | 구르기 |
| C | 앉기 |
| Q / E 짧게 누르기 | 캐릭터 특수 능력 |
| Q / E 2초 홀드 | 차원 전환 (Q = 이전, E = 다음) |
| 마우스 LB | 총 발사 |
| 마우스 RB | 조준 |
| R | 장전 |
| F | 상호작용 |

## 판정 규칙

- **구르기**: 이동 키를 누른 상태에서 Shift를 두 번 탭한다. 두 번째 입력이 0.25초 이내에 들어와야 구르기로 판정하고, 그보다 늦거나 제자리에서 두 번 누르면 달리기로 처리한다.
- **차원 전환**: Q/E를 2초 이상 누르고 있어야 한다. 홀드가 시작되면 화면이 흔들리고 화면 효과가 진행되며, 2초가 되는 순간 차원이 바뀐다. 2초 전에 키를 떼면 전환되지 않는다.
- **홀드 중 행동**: 차원 전환 연출 중에도 이동과 사격이 모두 가능하다.

## 전투 규칙

수치와 상태별 규칙은 [캐릭터 이동과 자세](character-movement.md)와 [전투 시스템](combat-system.md)에 확정했다. 이 절은 입력 관점의 요약이다.

- **달리기**: Shift를 누르고 있는 동안 유지된다.
- **구르기**: 피격 면역이 없고, 구르는 동안 사격할 수 없다. 이동 기술로만 쓴다.
- **앉기**: 이동 속도가 느려지는 대신 사격 정확도가 올라간다.
- **조준**: RB를 누르고 있는 동안 유지된다. 사격 정확도가 올라가고 이동 속도가 느려진다.
- **장전**: 탄창과 예비 탄약을 함께 쓴다. 탄창이 남아 있어도 R로 장전하고, 예비 탄약이 바닥나면 사격할 수 없다. 장전 중에는 사격할 수 없다.

## 구현 현황

이동(WASD)과 차원 전환 홀드(Q/E 2초)만 구현돼 있다. 사격·자세·회피·장전은 아직 코드가 없고, 차원 전환은 이 레벨 전용 데모 컨트롤러에 들어 있다.
