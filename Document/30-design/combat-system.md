# 전투 시스템

무기·탄약·명중·타격 연출의 확정 기획이다. 입력과 판정 시간은 [조작과 전투 규칙](controls.md), 자세와 이동 수치는 [캐릭터 이동과 자세](character-movement.md)에 있다.

## 체력과 데미지

| 항목 | 값 |
| --- | --- |
| 플레이어 최대 체력 | 100 |
| 더미 최대 체력 | 100 |
| 피스톨 1발 데미지 | 20 |
| 처치까지 필요한 명중 | 5발 |

- 체력은 GameplayAttribute(`Health`, `MaxHealth`)로 두고, 피해는 GameplayEffect로 적용한다.
- 체력이 0 이하가 되면 사망 처리한다. 플레이어는 3초 뒤 시작 지점에서 부활하고, 더미는 즉시 원래 위치에서 부활한다.

## 피스톨

| 항목 | 값 |
| --- | --- |
| 탄창 | 12 |
| 예비 탄약 | 60 |
| 연사 간격 | 0.15초 |
| 재장전 시간 | 1.2초 |
| 사거리 | 3000 |
| 투사체 속도 | 8000/s |
| 장전 중 행동 | 발사 불가, 이동·구르기 가능 |

- 발사는 홀드가 아니라 클릭 1회당 1발이다. 연사 간격이 지나기 전의 입력은 무시한다.
- 탄창이 0이면 발사되지 않고 빈 탄창 소리·탄퍼짐 표시만 난다.
- R은 탄창이 남아 있어도 재장전한다. 재장전이 끝나면 예비 탄약에서 부족분만큼 채운다.
- 예비 탄약이 0이면 재장전은 실패하고 아무 일도 일어나지 않는다.

## 탄퍼짐

발사 순간 조준 방향에 더해지는 각도다. 같은 상태에서 연속 발사하면 누적되고, 발사하지 않으면 0.2초당 1단계씩 줄어든다.

| 상태 | 기본 탄퍼짐 | 1발당 누적 | 최대 |
| --- | --- | --- | --- |
| `Stand_Idle` | 0.5° | 0.2° | 3.0° |
| `Stand_Walk` | 1.5° | 0.3° | 5.0° |
| `Stand_Run` | 4.0° | 0.4° | 8.0° |
| `Stand_Aim` | 0.1° | 0.15° | 1.5° |
| `Crouch_Idle` | 0.3° | 0.15° | 2.0° |
| `Crouch_Walk` | 1.0° | 0.25° | 3.5° |
| `Crouch_Aim` | 0.05° | 0.1° | 1.0° |
| `Jump_Fall` | 6.0° | 0.4° | 10.0° |
| `Roll` | 발사 불가 | 발사 불가 | 발사 불가 |

## 반동

발사할 때마다 조준점이 튀고 카메라가 짧게 흔들린다. 탄퍼짐(탄이 흩어지는 각도)과 별개로, 플레이어가 화면에서 느끼는 움직임이다.

| 항목 | 값 |
| --- | --- |
| 수직 튐(위) | 0.6°, 발당 |
| 수평 튐 | ±0.3°, 발당 |
| 조준점 회복 | 0.12초에 걸쳐 원래 방향으로 |
| 카메라 킥 | pitch −1.2°, 0.1초에 걸쳐 복귀 |

- 튐은 조준 방향에만 적용되고 캐릭터 몸의 회전은 바꾸지 않는다.
- 조준 중(Stand_Aim, Crouch_Aim)에는 튐이 50%로 줄어든다.
- 반동 회복 중에 다시 발사하면 회복을 멈추고 새 튐을 더한다.

## 총구 지연(벌어짐)

총구가 마우스 방향과 지금 얼마나 어긋나 있는지를 상태별로 정한다. 벌어짐의 원인은 캐릭터의 호흡과 움직임이며, 발사한 탄은 마우스가 아니라 **총구가 향한 방향**으로 날아간다. 조준선도 같은 방향을 그린다.

| 상태 | 최대 벌어짐 | 추종 속도 |
| --- | --- | --- |
| `Stand_Idle` | 1.5° | 90°/s |
| `Stand_Walk` | 6.0° | 60°/s |
| `Stand_Run` | 12.0° | 35°/s |
| `Stand_Aim` | 0.3° | 120°/s |
| `Crouch_Idle` | 0.8° | 90°/s |
| `Crouch_Walk` | 3.0° | 60°/s |
| `Crouch_Aim` | 0.2° | 140°/s |
| `Jump_Fall` | 8.0° | 45°/s |
| `Roll` | 발사 불가 | 발사 불가 |

계산 규칙:

1. **지속 벌어짐**: 마우스 방향으로 `추종 속도`만큼 따라잡는다. 벌어짐 크기는 상태의 `최대 벌어짐`을 넘지 않는다.
2. **호흡**: `Stand_Idle`·`Stand_Aim`·`Crouch_Idle`·`Crouch_Aim`에서 지속 벌어짐 위에 주기 4초, 진폭 0.4°의 사인파를 더한다. 가만히 있어도 조준선이 미세하게 좌우로 흔들리는 이유다.
3. **점프 충격**: 점프가 시작되는 순간 벌어짐에 25°를 한 번 더하고, 2.0초 동안 0으로 회복한다. 상태 상한은 1·2번 성분에만 적용하므로, 점프 직후에는 상한보다 크게 벌어졌다가 천천히 수렴한다.
4. **최종 총구 각도** = 마우스 방향 + (지속 벌어짐 + 호흡 + 점프 충격).

- 상태가 바뀌어 최대 벌어짐이 줄면(예: 달리다가 멈춤) 현재 벌어짐을 즉시 새 상한으로 자른다.
- 구르기 중에는 발사할 수 없고, 총구 각도는 구르기 종료 시의 마우스 방향으로 다시 수렴한다.

## 조준선

- 두께 2cm의 빨간 메시를 총구에서 사거리 3000까지 그린다. 실제 탄도와 같은 방향이다.
- 총구에서 조준선 방향으로 라인 트레이스해 벽·바닥에 닿으면 그 지점까지만 그린다. 뚫고 지나가지 않는다.
- 색은 변경하지 않는다(빨강 고정). 벽에 막혔는지는 길이로만 드러난다.
- 조준선은 화면 HUD가 아니라 월드에 있는 메시다. 카메라가 움직여도 벽에 붙은 끝점은 그대로다.

## 조준점(크로스헤어)

- 커서 위치에 십자 조준점을 그린다. 크기는 고정이고 위치만 커서를 따라간다.
- 십자 간격은 현재 탄퍼짐 각도를 화면 각도로 환산한 값에 비례한다. 계산은 `tan(탄퍼짐) × (뷰포트 반폭 ÷ tan(반FOV))`이며, 탄퍼짐이 커지면 벌어지고 줄면 좁아진다.
- 조준·재장전·사망·발사 중에도 숨기지 않는다. 커서가 뷰포트 밖에 있으면 화면 중앙에 그린다.
- 월드 빨간 조준선과 함께 쓴다. 조준선은 실제 탄도, 크로스헤어는 화면 기준 탄퍼짐 표시다.
- 위젯을 배치하지 않고 HUD 위젯이 직접 그린다(`NativePaint`). 커서를 매 프레임 따라가야 해서 배치 위젯보다 이쪽이 단순하다.

## 더미

- 테스트용 표적 3개를 레벨에 배치한다: 복도 `(-400, 800)`, 오피스 A `(300, -1200)`, 코어홀 `(300, 600)`. 바닥에서 캡슐 중심 90cm.
- 체력 100, 피격 시 데미지 숫자·색 플래시·넉백이 적용된다.
- 사망하면 같은 프레임에 원래 위치·회전·체력으로 돌아온다. 별도 부활 애니메이션 없음.
- 더미는 이동·공격하지 않는다.

## 적 체력 바

- 더미 머리 위에 160×16cm 크기의 월드 위젯을 띄운다. 캡슐 중심에서 120cm 위다.
- 만피일 때는 숨기고, 체력이 최대보다 낮아지면 보인다. 사망·부활로 다시 만피가 되면 숨긴다.
- 지연 바는 플레이어 HP 바와 같은 규칙을 쓴다: 0.5초 유지한 뒤 2.5초에 걸쳐 따라온다.

## 타격감

| 연출 | 규칙 |
| --- | --- |
| HP바 지연 감소(DelayedBar) | 맞은 순간 즉시 줄고, 0.5초 유지 후 2.5초 동안 현재 체력까지 따라 내려간다. |
| 데미지 숫자 | 맞은 지점 위에 실제 피해량을 띄운다. 0.8초 동안 위로 떠오르며 사라진다. |
| 피격 색 플래시 | 맞은 캐릭터의 색이 0.12초 흰색으로 바뀌고 0.25초 커브로 원래 색으로 돌아온다. |
| 히트스톱 | 명중 순간 전역 시간 배율을 0.15로 0.06초 유지한 뒤 즉시 1.0으로 복원한다. |
| 카메라 셰이크 | 명중 순간 진폭 1.5, 0.12초 셰이크를 발생시킨다. |
| 넉백 | 맞은 캐릭터를 발사 방향으로 250cm/s 밀어내고 0.15초 동안 감쇠한다. |
| 임팩트 파티클 | 맞은 지점에 0.3초짜리 파티클을 1회 재생한다. |
| 피격 화면 플래시 | 플레이어가 맞으면 화면 가장자리가 붉게 0.1초 번진다. |
| 조준선 확산 | 발사 순간 조준선이 탄퍼짐만큼 벌어졌다가 0.2초에 걸쳐 돌아온다. |

- 히트스톱은 반드시 원래 시간 배율로 복원한다. 예외 없이 0.06초 뒤 복원하고, 중첩되면 남은 시간을 갱신한다.
- 셰이크·파티클·사운드는 전용 클래스/에셋 없이 코드와 기본 도형으로 처리한다.

## 사운드

이번 범위에서는 소리를 재생하지 않는다. 발사·명중·재장전·사망 지점에 `USoundBase*` 속성만 두고, 값이 비어 있으면 조용히 넘어간다. 사운드 에셋은 이후 작업에서 채운다.
